Labirintus - Felhasználói útmutató

Játékprogram

Lépések

  1. Indítás: futtasd a játékot (game.sln).
  2. Pálya betöltése: kattints a fájl megnyitása gombra, és válassz egy pályát.
  3. Játékmenet: mozogj a nyilakkal, vagy a W, A, S, D billentyűkkel, térképezd fel a pályát és keresd a termeket, kijáratokat.
  4. Ha megvan az összes terem, akkor az egyik kijáraton hagyd el a pályát.
  5. Ha szeretnéd, mentheted a játékot a játék mentése gombra kattintva.

Irányítás (példa)

  • Fel: W
  • Le: S
  • Balra: A
  • Jobbra: D

További lehetőségek

  • Nyelvezet: a játékban válthatsz magyar és angol nyelv között egy kattintásra.
  • Pálya: ha szeretnéd, leleplezheted a pályát, hogy lásd a teljes térképet.
  • A jobb fent található nyilak azt mutatják, hogy melyik irányba lehet mozogni.

Rövid példa: egyszerű pálya (ASCII)

            .....╔══════╗...........
            ════╗║......║......█....
            .╔══╬╝..╔═══╣...╗..║....
            .║..║...║...╚═╦═╝╚╦╝....
            .╚╦═╩═══╣.....║...║.....
            ..╚══...║.....╚═══╝.....

█ = terem, . = üres tér

Szerkesztőprogram

Lépések

  1. Indítás: futtasd a szerkesztőt (LabirintusSzerkeszto-projekt).
  2. Pálya generálása: a magasság és a szélesség megadása után a pálya generálása gombra kattintva létrejön egy üres térkép.
  3. Pálya szerkesztése: a gombokra kattintva módosíthatod a pályát a választható elemekkel.
  4. Ha kész a pálya, elmentheted TXT-fájlként.

Tippek a szerkesztéshez

  • Alakíts ki zsákutcákat, a nehezebb játékmenetért.
  • Akár több termet / kijáratot is beletehetsz egy pályába.

Game Application

Steps

  1. Start: run the game (game.sln).
  2. Load a map: click the Open File button and select a map.
  3. Gameplay: move using the arrow keys or the W, A, S, D keys, explore the map and find the rooms and exits.
  4. Once all rooms have been found, leave the map through one of the exits.
  5. If you wish, you can save your progress by clicking the Save Game button.

Controls (example)

  • Up: W
  • Down: S
  • Left: A
  • Right: D

Additional Features

  • Language: you can switch between Hungarian and English with a single click.
  • Map: if you want, you can reveal the entire map to see the full layout.
  • The arrows in the top-right corner indicate the directions in which movement is possible.

█ = room, . = empty space

Editor Application

Steps

  1. Start: run the editor (LabirintusSzerkeszto-project).
  2. Generate a map: after entering the height and width, click the Generate Map button to create an empty map.
  3. Edit the map: click the available buttons to modify the map using the selectable elements.
  4. Once the map is finished, it can be saved as a TXT-file.

Editing Tips

  • Create dead ends to make the gameplay more challenging.
  • You can add multiple rooms and exits to a map.
