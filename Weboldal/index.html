Játékprogram

Lépések (rövid)

  1. Indítás: futtasd a játékot (exe vagy index.html a böngészőben).
  2. Pálya választás: válassz egy beépített vagy mentett pályát.
  3. Játékmenet: mozogj, gyűjts tárgyakat, keresd a kijáratot.
  4. Mentés/lezárás: játékmentés és kilépés.

Irányítás (példa)

  • Fel: W / Fel nyíl
  • Le: S / Le nyíl
  • Balra: A / Bal nyíl
  • Jobbra: D / Jobb nyíl
  • Pauza: Esc

Gyakori hibák & megoldások

  • Nem reagálnak a billentyűk — ellenőrizd, hogy a játékablak fókuszban van.
  • Pálya nem töltődik — nézd meg a konzol/log fájlt, vagy próbáld újra betölteni a pályát.
  • FPS lassú — csökkentsd a látótávolságot/beállításokat.

Rövid példa: egyszerű pálya (ASCII)

            #########
            #S  #   #
            # ## # E#
            #      ##
            #########

S = Start, E = Exit

Szerkesztőprogram

Gyors lépések

  1. Új pálya: Fájl → Új → válassz méretet (pl. 20x15).
  2. Eszközök: ceruza (fal), radír, start/exit jelölő.
  3. Mentés: Fájl → Mentés (export .json vagy saját formátum).
  4. Tesztelés: Nyomd meg a 'Teszt' gombot a szerkesztőből.

Eszközök és tulajdonságok (példa)

  • Fal: blokk típus, ütközés engedélyezett.
  • Start/Exit: pont kezdéshez/véghez.
  • Trigger: esemény, amikor a játékos áthalad.

Tippek a szerkesztéshez

  • Használj sablonokat kezdő pályához.
  • Rendszeresen ments gyakori változtatáskor.
  • Teszteld a pályát különböző nehézségeken.

Game Application

Steps (short)

  1. Start the game (exe or open index.html in browser).
  2. Select a level or load a saved map.
  3. Play: move, collect items, find the exit.
  4. Save/quit when finished.

Controls (example)

  • Up: W / Arrow Up
  • Down: S / Arrow Down
  • Left: A / Arrow Left
  • Right: D / Arrow Right
  • Pause: Esc

Common issues & fixes

  • Keys not working — ensure the game window has focus.
  • Level doesn't load — check console/log or reload the level.
  • Low FPS — lower graphics settings or view distance.

Editor Application

Quick steps

  1. Create new map: File → New → choose size (e.g. 20x15).
  2. Tools: pencil (wall), eraser, start/exit markers.
  3. Save: File → Save (export .json or internal format).
  4. Test: press 'Test' to run the map from the editor.

Tools & properties (example)

  • Wall: blocking tile with collision.
  • Start/Exit: define player start and level exit.
  • Trigger: fires events when player steps on it.

Editing tips

  • Use templates for base layouts.
  • Keep frequent backups while editing.
  • Test maps with different difficulty settings.
